# Testing guide
`npm test` (Vitest, real Postgres `TEST_DATABASE_URL`): `matching.test.ts` (21, pure engine), `identity.test.ts` (11), `marketplace.test.ts` (21: posting rules, application workflow, ownership/cross-account checks, DB matching, talent privacy, audit immutability, transaction rollback), `admin.test.ts` (10: RBAC matrix, service-level permission enforcement, suspension, moderation, verification, versioned rules). `node tests/e2e/journey.mjs` runs an 18-step Playwright journey (worker register→verify→onboard→recommend→apply→save; business post/validation/pipeline/offer→worker accept→filled; talent privacy; cross-business 404; admin dashboard/suspend/audit/RBAC/rules; mobile 390px no horizontal scroll) against a built app (`next start -p 3100`, seeded DB, `BASE_URL` to override).
**Not covered:** password-reset and logout through the browser, tablet viewport, automated accessibility audit (axe), load/performance, payments (not built), file upload security (not built). Manual WCAG 2.2 AA verification has **not** been performed; contrast tokens were chosen for AA but not measured.
