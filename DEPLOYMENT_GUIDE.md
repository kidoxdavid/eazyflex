# Deployment guide
Not yet deployed anywhere; no CI/CD exists. Suggested path: managed PostgreSQL (Canadian region), Node 22 host or container for `next build && next start`, run `npm run db:migrate` as a release step, set env vars (below), serve behind HTTPS (cookies are `Secure` in production). **Email:** set `EMAIL_DRIVER=smtp`, `SMTP_URL`, `EMAIL_FROM` and run `npm run emails:send` every minute or so (cron/scheduler) — there is no in-process queue. **Alerts:** schedule `npm run alerts:send` (e.g. daily or hourly) — nothing runs it automatically. **Storage:** `STORAGE_DIR` must be a persistent private volume (local driver only; add S3-compatible storage for multi-instance deployments). **Before launch you must:** verify SPF/DKIM for the sending domain, run the app as a non-owner DB role, add backups, monitoring (Sentry), CSP, and complete legal/privacy review. Never run `db:seed`/`db:reset` against production (both refuse when `NODE_ENV=production`, but do not rely on that alone).
