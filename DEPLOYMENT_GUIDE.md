# Deployment guide
Not yet deployed anywhere; no CI/CD exists. Suggested path: managed PostgreSQL (Canadian region), Node 22 host or container for `next build && next start`, run `npm run db:migrate` as a release step, set env vars (below), serve behind HTTPS (cookies are `Secure` in production). **Before launch you must:** configure a real transactional email provider (the only driver is `outbox`, which delivers nothing), run the app as a non-owner DB role, add backups, monitoring (Sentry), CSP, and complete legal/privacy review. Never run `db:seed`/`db:reset` against production (both refuse when `NODE_ENV=production`, but do not rely on that alone).
